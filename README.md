# Musical Instruments API

Навчальний REST API сервіс для управління списком музичних інструментів, реалізований за допомогою **ASP.NET Core Minimal API** та сховища в оперативній пам'яті (In-Memory).

---

## 📌 Основний функціонал

Проєкт демонструє роботу з колекціями даних, потокобезпечність та базові принципи REST API:
* Отримання повного списку інструментів
* Додавання нового інструмента з валідацією вхідних даних (перевірка на непорожнє ім'я та невід'ємну ціну)
* Вилучення інструмента за назвою (без урахування регістру)
* Вилучення інструментів за числовим критерієм (ID перевищує задане порогове значення)
* Повне очищення списку з пам'яті

---

## 🛠 Технологічний стек

* **Платформа:** .NET 8 / .NET 9
* **Фреймворк:** ASP.NET Core (Minimal APIs)
* **Мова:** C#
* **Архітектурні особливості:** 
  * Шаблон **Repository** для ізоляції логіки збереження даних
  * Синхронізація потоків за допомогою механізму **`lock`** для безпечної паралельної обробки запитів
  * **Dependency Injection** (реєстрація сховища як `Singleton`)
  * Потокобезпечна генерація ідентифікаторів через **`Interlocked.Increment`**

---

## 🚀 Ендпоінти API

| Метод | Маршрут | Опис |
| :--- | :--- | :--- |
| `GET` | `/instruments` | Отримати список усіх зареєстрованих інструментів |
| `POST` | `/instruments` | Створити новий інструмент (передається JSON у тілі) |
| `DELETE` | `/instruments/by-name/{name}` | Видалити інструмент за назвою |
| `DELETE` | `/instruments/by-id-greater/{threshold}` | Видалити всі інструменти, де `Id > threshold` |
| `DELETE` | `/instruments/clear` | Очистити все сховище даних |
